# (pkg/composer/imported/generated) against a real `terraform providers
# schema -json` dump and flags any nested-object literal missing a
# provider-Required sub-attribute (the odb_network_arn bug class, #839).
#
# Entries here are misses that are KNOWN and issue-tracked but not yet
# fixed in the generated model — they print as ALLOWED(stale-model)

# cite the issue that will remove it (driftscan hard-errors on an entry
# with no `#<issue>` citation), and a row is deleted the moment its model
# regenerates.
#
